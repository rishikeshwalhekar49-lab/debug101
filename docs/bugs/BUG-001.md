# BUG-001: "Dead file `validation/multiseedagent.py`" — closed, the report was wrong

## Status: CLOSED on 2026-11-15, not a bug. Do not delete the file.

## What the report said
That `validation/multiseedagent.py` is dead code and `validation/multiseed_agent.py` is the live implementation, with a planned fix of `git rm silent_bug_agent/validation/multiseedagent.py`.

## What is true
It is the other way round:

- `validation/multiseedagent.py` is the **real implementation** of Gate 2 (`MultiseedAgent`, `compare_distributions`, `compute_cohens_d`, ...).
- `validation/multiseed_agent.py` is a 19-line alias that only re-exports those names.
- `agents/supervisor.py` and `tests/test_multiseed_agent.py` import from `multiseedagent`.

Check it yourself:

```bash
grep -rn "multiseedagent" silent_bug_agent/ tests/
head -5 silent_bug_agent/validation/multiseed_agent.py
```

Carrying out the planned fix would have deleted the multi-seed statistical gate.

## If the duplicate name bothers you
Remove the alias (`multiseed_agent.py`), not the implementation, after checking nothing imports it, and run the full test suite.
